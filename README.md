# Holiday World Content Launch

A client-side launch QA tool for Holiday World-style magazine, marketplace and streaming catalogs. Paste content records and the tool flags unsupported surfaces, missing assets or owners, invalid release dates and duplicate titles. It runs entirely in the browser and stores no data.

## Run

Open `index.html` in a browser. No server, dependency, or API key is required.

## Test

```bash
node test.js
```
